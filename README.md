# 🎯 Guessing Game

A simple number guessing game built with **Python** and **Tkinter** GUI.  
This is one of my hobby projects created to explore how to build GUIs using Tkinter and convert `.py` files into executable `.exe` applications.

---

## 🕹️ Game Mechanics

- 🎲 **Objective**: Guess the secret number between **1 and 10**.
- ✅ If the guess is **correct**, a message box will display "**🎉 Congratulations!**".
- 🤏 If the guess is **close** (within ±2 of the correct number), it shows "**⚠️ Close Guess**".
- ❌ If the user enters a **non-numeric input** (letters or symbols), it shows an "**Invalid Input**" message.
- 🔄 Click the **Restart** button to reset the attempt counter to **0**.

---

## 🧪 How to Try It

1. Download or clone this repository.
2. Navigate to the `dist` folder.
3. Run the **executable file** (`.exe`) to play the game — no Python installation required!
